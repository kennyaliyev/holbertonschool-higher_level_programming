# Python Object Relational Mapping

This directory contains Python scripts that demonstrate how to interact with MySQL databases using the MySQLdb module.

## Requirements

- Python 3
- MySQLdb (mysqlclient) module: `pip3 install mysqlclient`
- MySQL server running on localhost:3306

## Files

- `0-select_states.py`: Lists all states from the hbtn_0e_0_usa database
